# Управление

## Клавиатура

| Клавиша      | Действие      | Описание                                          |
| :----------- | :------------ | :------------------------------------------------ |
| **↑ ← ↓ →**  | Движение      | Перемещение игрока в соответствующем направлении. |
| **Z**        | Отмена (Undo) | Отменяет последний ход.                           |
| **R**        | Сброс (Reset) | Начинает текущий уровень заново.                  |
| **Ctrl + R** | Новый уровень | Генерирует новый случайный уровень.               |
| **S**        | Рекорды       | Открывает/закрывает окно с таблицей рекордов.     |

## Мышь

Мышь используется только для взаимодействия с UI окнами (таблица рекордов, окно победы):

- **Клик** по кнопкам ("Закрыть", "Новый уровень").
- **Наведение** на кнопки (изменение цвета).
- **Клик** по крестику [X] для закрытия окон.

## Интерфейс

В нижней части окна отображается строка статуса:

- **Обычный режим**: Подсказка с клавишами управления.
- **Победа**: Сообщение "Поздравляю! Уровень пройден! Время: ... | Ходов: ...".
