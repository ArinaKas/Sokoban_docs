Правила игры

Правила игры

Цель

Расставить все ящики (коробки) на целевые позиции (отмечены на полу).

Основные правила

  1. Толкание: Игрок может толкать только один ящик за раз.
  2. Нельзя тянуть: Игрок может только толкать ящики, но не тянуть их за собой.
  3. Препятствия:
    • Нельзя толкать ящик в стену.
    • Нельзя толкать ящик в другой ящик.
  4. Границы: Игрок не может выходить за пределы игрового поля.

Отмена ходов (Undo)

  • Нажатие Z отменяет последний ход.
  • История хранит до 50 последних состояний. Если история переполнена, самые старые ходы удаляются.
  • Отмена хода восстанавливает позицию игрока, ящиков и направление взгляда.

Условия победы

Уровень считается пройденным, когда все ящики находятся на целевых клетках. При победе:

  1. Останавливается таймер.
  2. Показывается окно с результатами.
  3. Рекорд сохраняется в таблицу.

Система рекордов

Рекорд состоит из трех параметров:

  • Время: Секунды, затраченные на прохождение.
  • Ходы: Количество совершенных перемещений.
  • Сложность: Количество ящиков на уровне.

При просмотре таблицы рекордов (S) текущий результат подсвечивается зеленым цветом.
