Описание игры

Об игре Sokoban

Sokoban (яп. 倉庫番, "складской рабочий") - это логическая игра-головоломка, в которой игрок управляет персонажем, который должен расставить ящики на обозначенные целевые позиции в складском помещении.

Описание проекта

Данная реализация игры Sokoban написана на Java с использованием Swing для графического интерфейса.

Основные характеристики:

  • Размер поля: 10x10 клеток
  • Размер клетки: 64x64 пикселя
  • Графика: спрайтовая (PNG изображения)
  • Генерация уровней: процедурная или предустановленная

Игровой процесс

Игрок управляет персонажем, который может:

  • Перемещаться по полю (вверх, вниз, влево, вправо)
  • Толкать ящики (но не тянуть)
  • Отменять свои ходы

Цель игры: расставить все ящики на целевые позиции (отмечены желтым цветом).

Технические особенности

  • Язык программирования: Java 8+
  • GUI фреймворк: Swing
  • Архитектура: MVC-подобная
  • Система отмены: на основе стека состояний (Memento pattern)
  • Сохранение рекордов: файловая система
