# Сборка проекта

Проект можно собрать вручную через командную строку или используя IDE.

## Ручная сборка (Command Line)

1. **Навигация в папку проекта**

    ```bash
    cd /path/to/your/project
    ```

2. **Компиляция**

    Так как есть зависимости между пакетами, компилируем всё рекурсивно:

    ```bash
    javac -d out **/*.java
    ```

    _Это создаст папку out со всеми скомпилированными .class файлами_

3. **Копирование ресурсов**

    Убедитесь, что папка resources находится рядом с скомпилированными классами или в корне JAR-архива, иначе спрайты не загрузятся

## Сборка в IntelliJ IDEA

1. Откройте папку проекта в IDEA

2. Подождите индексацию

3. Нажмите Build -> Build Project (Ctrl+F9)
