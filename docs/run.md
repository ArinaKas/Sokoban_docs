# Запуск игры

## Через IDE

1. Откройте файл `game/Main.java`.
2. Нажмите кнопку "Run" (зеленый треугольник) рядом с классом или методом `main`.

## Через командную строку

Если вы скомпилировали проект в папку `out`:

```bash
java -cp out game.Main
```

## Распаковка ресурсов

Важно: При запуске убедитесь, что папка `resources` с картинками доступна

В коде используется относительный путь:

```java
spriteManager.loadImage("resources/images/ui/button.png");
```
