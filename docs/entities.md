# Сущности игры

## Классы сущностей

### Player (Игрок)

**Файл**: `Player.java`

Простой класс, представляющий игрока на игровом поле.

**Поля**:

- `int x, y` - координаты игрока на сетке (в клетках)

**Основные методы**:

1\. `move(int dx, int dy)`

Перемещает игрока на указанное смещение:

```java
public void move(int dx, int dy) {
    x += dx;
    y += dy;
}
```

2\. `setPosition(int x, int y)`

Устанавливает абсолютную позицию игрока

**Особенности**:

- Игрок не знает о коллизиях - проверка происходит в `GamePanel`

- Направление движения хранится отдельно в `SpriteManager`

### GameBox (Ящик)

**Файл:** `GameBox.java`

Класс, представляющий ящик, который игрок должен толкать на цели

**Поля**:

- `int x, y` - координаты ящика

- `boolean onTarget` - находится ли ящик на целевой позиции

**Метод** `setPosition(int x, int y)` устанавливает новую позицию ящика

**Логика:**

- При создании `onTarget = false`

- Значение `onTarget` обновляется в `GamePanel.moveBox()` после каждого перемещения

- Проверка: `targets.contains(new Point(x, y))`

### BoxState (Состояние ящика)

**Файл:** `BoxState.java`

Вспомогательный класс для реализации системы отмены ходов (паттерн Memento)

**Поля:**

- `int x, y `- сохраненные координаты

- `boolean onTarget` - сохраненное состояние цели

**Назначение:**

Хранит "снимок" состояния ящика в конкретный момент времени для возможности отката

### GameState (Состояние игры)

**Файл:** `GameState.java`

Основной класс для системы отмены ходов. Хранит полное состояние игры

**Поля:**

- `int playerX, playerY` - позиция игрока

- `int playerDx, playerDy` - последнее направление движения игрока

- `List<BoxState> boxStates` - список состояний всех ящиков

**Конструктор**:

```java
public GameState(int playerX, int playerY, int playerDx, int playerDy, List<GameBox> boxes)
```

Создает копию состояния всех ящиков (deep copy)

**Метод** `restore(GamePanel panel)`:

Восстанавливает состояние игры из сохраненного снимка:

1. Восстанавливает позицию игрока

2. Восстанавливает направление взгляда

3. Восстанавливает позиции и состояния всех ящиков

### TileType (Тип плитки)

**Файл:** `TileType.java`

Перечисление типов клеток игрового поля

**Значения:**

- `FLOOR` - пол (проходимая клетка)

- `WALL` - стена (непроходимая)

- `TARGET` - целевая позиция (для ящика)

- `BOX_ON_TARGET` - ящик на цели (специальный тип для отрисовки)

**Использование:**

Хранится в двумерном массиве `TileType[][] grid` в классе `GamePanel` для представления статической части уровня (стены и цели)
