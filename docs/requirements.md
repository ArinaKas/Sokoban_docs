# Системные требования

Для запуска и разработки игры Sokoban вам потребуется:

### Программное обеспечение

- **Java Development Kit (JDK)** версии 8 или выше.
- **Среда разработки**: IntelliJ IDEA (рекомендуется), Eclipse или VS Code.
- **Git** (для клонирования репозитория, если применимо).

### Аппаратные требования

- **ОС**: Windows, macOS, Linux.
- **ОЗУ**: минимум 256 МБ (игра потребляет очень мало ресурсов).
- **Дисплей**: Разрешение минимум 800x600 (для корректного отображения окна 640x640).
