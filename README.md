# Sokoban_docs

Репозиторий документации к игре Sokoban

Быстрый просмотр:

скачиваем Node.js - среда выполнения JavaScript

в терминале vs code папки docs инициализируем `npx honkit init .`

запускаем локально `npx honkit serve`

при ошибке запуска .ps1-скриптов во время инициализации:

`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`
подтверждаем Yes и после этого снова `npx honkit init .`
